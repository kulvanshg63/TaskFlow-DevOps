# TaskFlow - DevOps Automated Task Management System

## Project Overview

TaskFlow is a web-based task management application developed as a DevOps and Automation capstone project.

The project demonstrates software development together with DevOps practices such as version control, continuous integration, containerization and automated deployment.

## Problem Statement

Manual task management and manual software delivery can be inefficient and difficult to maintain.

TaskFlow provides a simple task management application while demonstrating an automated DevOps workflow.

## Objectives

- Develop a task management application.
- Implement CRUD operations.
- Maintain the project using Git and GitHub.
- Use branches for feature development.
- Demonstrate merging and merge conflict resolution.
- Implement Continuous Integration using Jenkins.
- Containerize the application using Docker.
- Deploy the application using Kubernetes.
- Implement monitoring, logging and security.
